# Heatmaps

The heatmaps frontend renders comparison matrices for backoffice analytics. See [Analytics](../analytics/README.md) for the supported dimensions, API contracts, data sources and flow diagrams.

## Sprint History

### Sprint 3

The matrix scrolls horizontally inside its labeled region. Keyboard users can focus that region and use the arrow keys to reach columns outside the viewport. See [Analytics](../analytics/README.md#sprint-history) for the shared history.
